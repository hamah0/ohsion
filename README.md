# 오시온의 휴대폰

SKY 네온사인폰(IM-U300K, 2008) 스타일의 레트로 폴더폰을 웹에서 조작하는 인터랙티브 사이트입니다.
HTML · CSS · 순수 JavaScript만 사용해서 GitHub Pages에서 그대로 돌아갑니다.

## 폴더 구조
```
index.html      휴대폰 뼈대 (외형, 버튼 배치)
css/style.css   디자인 (색상, 광택, LED, 화면)
js/data.js      ★ 설정 (시계, 첫 장면, LED, 메뉴)
js/messages.js  ★ 문자 기록 (받은 문자함 · 보낸 문자함 · 임시 저장함)
js/contacts.js  ★ 전화번호부 (연락처 이름 · 번호)
js/memos.js     ★ 메모장 (시온의 메모)
js/photos.js    ★ 사진첩 목록 (사진 파일 경로)
js/calls.js     ★ 통화기록
js/schedule.js  ★ 일정 (2009년 달력, 공휴일)
js/music.js     ★ 뮤직 플레이어 곡 목록 (제목 · 가수 · 길이)
js/show.js      ★ SHOW 포털 (2009년풍 · 외부 연결 없음)
js/music-player.js  뮤직 플레이어 재생 시뮬레이션 (소리 없음)
images/wallpaper.png  기본 배경화면 사진 (js/data.js 의 wallpaper)
images/photos/  사진첩 사진 photo01.jpg ~ photo11.jpg (원본 그대로)
js/viewer.js    사진·문자 큰 보기 창
js/closeup.js   클로즈업(확대 보기) · 화면 맞춤
js/phone.js     동작 (폴더 열기/닫기, 키패드, 메뉴)
```

## 조작 방법
- 오른쪽 위 `폴더 열기` / `폴더 닫기` (스페이스바, 열린 상태에서 힌지를 눌러도 닫혀요). 닫힌 폰을 눌러도 열려요
- 열린 폰의 화면을 누르면 화면 쪽으로 클로즈업 → 그 상태에서 메뉴를 눌러 조작
- 오른쪽 위 `클로즈업` / `클로즈업 해제` (닫혀 있으면 외부 화면·LED 클로즈업)
- 두 손가락(모바일) · 키보드 `+` `−` 로 확대·축소, 드래그·마우스 휠로 이동 (휠로는 확대되지 않아요)
- 전화번호부: 메뉴 6번 또는 대기화면 `전화번호부` → ㄱㄴㄷ 순 목록 → 연락처. 숫자키로 초성 찾기(1 ㄱ, 4 ㄷ, 5 ㄴㄹ, 7 ㅁㅅ, 8 ㅂ, * ㅈㅊ, 0 ㅇㅎ), 상세 화면에서 `문자` → 그 사람과 주고받은 문자, 통화 키 → 번호 입력 화면
- 클로즈업 해제: 버튼, 휴대폰 바깥 빈 곳 클릭, 브라우저 뒤로 가기
- 확인(가운데 ▶) → 메뉴, 방향키로 이동, 숫자 1~9로 바로 열기
- C/P 또는 화면 아래 `뒤로`·`목록` → 뒤로, 빨간 종료 버튼 → 대기화면
- 문자함: 메뉴 1번(또는 키패드 위 봉투 키) → 받은/보낸/임시 저장함 → 목록 → 문자. 상세 화면에서 ←/→ 이전·다음 문자, `크게`(또는 확인) → 큰 글자로 보기
- 사진첩: 메뉴 3번 → 사진 목록(3칸) → 사진. 보기 화면에서 ←/→(또는 ◀ ▶) 이전·다음 사진, `크게`(또는 확인·사진 누르기) → 큰 보기 창. 큰 보기에서도 ◀ ▶ 버튼, 키보드 ←/→, 좌우로 밀기로 넘기기
- 컴퓨터 키보드: 방향키, Enter(확인), Backspace(C/P), Esc(종료), 숫자

## GitHub Pages에 올리기
1. GitHub에서 새 저장소(Repository)를 만듭니다. (Public)
2. `Add file → Upload files`로 이 폴더 안의 파일과 폴더(css, js 포함)를 그대로 끌어다 놓고 Commit.
3. 저장소 `Settings → Pages` → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
4. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/저장소이름/`)로 접속하면 끝!

## 꾸미기 (js/data.js)
- `intro` : 첫 장면(문자 도착) — 날짜, 저장명, 날짜가 보이는 시간, 웃는 얼굴 LED 그림. `intro: null` 이면 연출 없이 시작
- `keySound` : 버튼음 켜기 `true` / 끄기 `false`
- `clock` : 이야기 속 날짜·시각으로 고정
- `wallpaper` : 대기화면 배경 사진 (images 폴더에 넣고 경로 입력)
- `outerMessages` : 닫힌 폰 외부 화면에 흐르는 문구
- `ledPatterns` : LED 도트 그림 (11×9, `p` 분홍 / `b` 파랑)

## 문자 추가하기 (js/messages.js)
```js
inbox: [
  { from: "보낸 사람 저장명", date: "2009-11-03 18:40", body: "문자 내용" },
],
sent:   [ { to: "받는 사람", date: "2009-11-03 18:42", body: "문자 내용" } ],
drafts: [ { to: "받는 사람", date: "2009-12-24 21:50", body: "보내지 못한 문자" } ],
```
- 요일은 날짜로 자동 계산돼요 (2009년 실제 달력)
- 목록에는 날짜가 바뀌는 곳마다 날짜 구분줄이 생기고, 각 줄에는 시각이 표시돼요
- 같은 분(分)에 받은 문자와 보낸 문자가 있으면 '받은 문자 → 보낸 문자' 순서가 기본이에요. 반대로 하려면 date 에 초를 붙여요 ("2009-10-24 15:23:30", 화면엔 안 보임)
- 문자함 4번 `대화별 보기` → 사람별로 주고받은 문자만 모아 보기 (새로운 이름이 문자에 나오면 자동으로 생겨요)
- 이야기 기간은 2009-01-01 ~ 12-24 22:24 (5월 같은 과거 기록도 OK) (전화번호부 → 이름 → `문자` 에서 두 사람의 문자를 한 줄로 이어 볼 수 있어요)
- `unread: true` → 읽지 않은 문자(닫힌 봉투), 대기화면에 "새 문자 N통" 알림
- 날짜가 틀리거나 2009.09.01 ~ 2009.12.24 22:24 밖이면 F12 콘솔에 경고가 떠요

## 연락처 추가·수정하기 (js/contacts.js)
```js
{ no: 18, name: "이름", tel: "010-000-0000" },
```
- 화면에서는 ㄱㄴㄷ 순으로 자동 정렬돼요
- `name` 이 문자 기록의 `from`/`to` 와 글자까지 똑같으면 문자 상세에 번호가 표시되고, 전화번호부에서 그 사람의 문자를 모아 볼 수 있어요

## 메모 추가하기 (js/memos.js)
```js
{ date: "2009-10-01", title: "메모 제목", body: `메모 내용
두 번째 줄` },
```
- 화면에서는 날짜순(오래된 것부터)으로 정렬, 요일 자동 계산
- 백틱(`)으로 감싸면 줄바꿈·빈 줄 그대로. "1. ..." 로 시작하는 줄은 번호 목록으로 정렬돼요

## 통화기록 추가하기 (js/calls.js)
```js
{ dir: "out", name: "우시우시", date: "2009-11-03 18:40" },                    // 발신
{ dir: "in",  name: "우시우시", date: "2009-11-03 18:40" },                    // 수신
{ dir: "in",  name: "우시우시", date: "2009-11-03 18:40", answered: false },   // 부재중
{ dir: "out", name: "우시우시", date: "2009-11-03 18:40", answered: false },   // 발신 · 거절
```
- 메뉴 2번 `통화기록` (또는 대기화면에서 초록 통화 키) → 전체/발신/수신/부재중 탭 (←/→ 로 바꾸기)
- 이름이 전화번호부와 같으면 번호가 표시되고, 전화번호부 상세에 "통화기록 N건"이 생겨요

## 일정 추가하기 (js/schedule.js)
```js
{ date: "2009-11-03", title: "일정 이름" },
```
- 메뉴 8번 `일정` → 2009년 달력 (12월 24일에서 시작). 방향키로 날짜 이동, `*`/`#` 또는 ◀ ▶ 로 이전·다음 달
- 일정 있는 날은 작은 점, 일요일·공휴일은 빨간색, 토요일은 파란색. `목록` → 모든 일정 보기

## 곡 추가하기 (js/music.js)
```js
{ title: "곡 제목", artist: "가수", length: "03:45" },
```
- 메뉴 7번 `음악` → 곡 목록 → 곡 선택 → `▶` 재생 (소리는 나지 않고 재생바·시간만 움직여요)
- `❚❚` 일시정지 / `정지` / `◀◀ ▶▶` 이전·다음 곡 (재생 중이면 이어서 재생) / 재생바를 누르거나 끌어서 위치 이동
- 곡이 끝나면 '재생 완료'로 멈추고 재생바가 처음으로 돌아가요. `length` 를 비우면 04:00

## SHOW 포털 (js/show.js)
- 메뉴 5번 `SHOW` → 접속중… → 포털 첫 화면 (검색 · 뉴스 · 날씨 · 운세 · 음악 · 게임 · 벨소리 · 사진·이미지 · 생활정보)
- 숫자키 1~9로 바로 이동, `*` 또는 C/P = 이전, `#` 또는 `처음` = 포털 첫 화면
- 뉴스·게임·벨소리·생활정보는 제목만 보여요. 날씨는 2009년 12월 25일 기록과 26일 예보(기상청 발표, 한국일보 2009.12.28 기사 기준)
- 글·목록을 바꾸거나 추가하려면 js/show.js 의 해당 메뉴 안 items 를 고치면 돼요. page 없이 { label: "제목" } 만 쓰면 제목만 보이는 줄이 돼요

## 설정 (메뉴 9번)
- 소리(벨소리 크기·버튼음) / 화면 밝기 5단계 / 벨소리 / 배경화면 / 12·24시간제 / 휴대폰 잠금(켜짐·꺼짐 표시만) / 언어(한국어) / 휴대폰 정보
- 바꾼 값은 브라우저에 저장돼서 다시 들어와도 유지돼요. 처음 상태로 되돌리려면 브라우저의 사이트 데이터를 지우면 돼요

## 우시우시의 전화 (js/data.js 의 incomingCall)
- 보낸 문자함의 12/24 22:23 고백과 받은 문자함의 22:24 답장을 둘 다 열어 보면 6초 뒤 전화가 와요 (접속 한 번에 한 번)
- 벨소리는 설정 > 벨소리(무음이면 소리 없음)·소리 > 벨소리 크기(0이면 소리 없음)를 따라요. 약 40초 뒤엔 소리만 멈추고 수신 화면은 계속 보여요
- `통화`(초록 키) → 대사가 순서대로 한 줄씩, `넘기기`로 다음 대사, `종료`(빨간 키)로 끊기
- `거절` → 통화기록에 '부재중', 약 5초 뒤 우시우시가 다시 전화 (재전화는 첫 전화를 거절했을 때만)
  - 재전화를 받으면 재전화 대사가 5초 간격으로 한 줄씩, 끝나면 통화 종료
  - 재전화도 거절하거나 40초 동안 받지 않으면 '부재중'으로 끝나요 (대사 없음)
  - 재전화 대사·간격·기다리는 시간은 incomingCall.recall 의 lines · gaps · afterReject · noAnswer
- 폴더가 닫혀 있으면 외부 화면에 '☏ 우시우시'가 깜빡이고, 열면 수신 화면이 나와요
- 대사·간격·기다리는 시간은 incomingCall 의 lines · gaps · delay 에서 바꿔요
